Live Tracking

Requires server.py running (see requirements.txt) -- the browser can't reach Motive on its own. Assign each incoming rigid body below to a camera or prop to drive its position/rotation live.

Live rotation offset (deg)

Live rotation isn't calibrated by default -- see js/motive/liveTracking.js. Point the tracked object at a known heading and adjust this until the displayed rotation matches reality.

GitHub Sync

Saves this setup (all its positions, props, frame grabs) as one JSON file (setups/<id>.json, overwritten on every save) to the repo above, via GitHub's API. The token is stored only in this browser — use a fine-grained token scoped to just that one repo with Contents: read/write.
